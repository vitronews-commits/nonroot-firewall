# NonRoot Firewall

Minimal Android no-root firewall project inspired by the classic NoRoot Firewall user experience.

**Status: early scaffold, NOT a working firewall.** The VPN service is intentionally inactive. The policy model defaults to PENDING (ask), but it is not connected to network traffic yet.

## Build
Open in Android Studio with JDK 17, Android SDK 35 and Gradle 8.9+; sync and build the app module. No APK has been verified yet.
